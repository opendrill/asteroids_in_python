This is just a short project to try out UV and practice using classes, inheritance, and other OOP concepts in Python.

It is just a simplified version of the old game Asteroids.

Prerequisites:
  1) Python 3.13
  2) Pygame 2.6.1

If you want to play this:
  1) Clone this repo.
  2) cd into the newly created "asteroids_in_python" directory.
  3) Create and activate a virtual environment with the prerequisites installed.
  4) Run the command "python3 main.py" in the activated virtual environment.
